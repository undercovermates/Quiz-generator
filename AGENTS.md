## AI Quiz Generator

This project is an AI-powered quiz generator that uses a Node.js backend and a vanilla JavaScript frontend.

### How to run the application

1.  **Install dependencies:**
    Open a terminal and run the following command to install the required Node.js packages:
    ```bash
    npm install
    ```

2.  **Start the server:**
    After the installation is complete, start the backend server by running:
    ```bash
    node server.js
    ```

3.  **Access the application:**
    Open your web browser and navigate to `http://localhost:3000`. You should see the AI Quiz Generator application.
